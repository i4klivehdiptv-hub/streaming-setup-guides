# Streaming Setup and Troubleshooting Guide

This repository provides practical information for setting up streaming devices, configuring compatible media players, and troubleshooting common playback issues.

## Topics covered

- Preparing a Fire TV Stick or Android TV device
- Installing compatible media-player applications
- Understanding M3U playlists and Xtream Codes login details
- Improving home Wi-Fi performance
- Troubleshooting buffering and playback errors
- Configuring an electronic programme guide (EPG)

## Connection and buffering tips

- Test your internet connection on the device you use for streaming.
- Prefer Ethernet or a stable 5 GHz Wi-Fi connection when available.
- Restart your router and streaming device if playback repeatedly fails.
- Keep your device and media-player application updated.
